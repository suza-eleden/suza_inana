# Formulario único para inspección de edificaciones después de un sismo

Fuente: *Guía Técnica para la Inspección de Edificaciones Después de un Sismo* (AIS — Asociación Colombiana de Ingeniería Sísmica). Formato de 2 páginas.

Las preguntas se transcriben en el orden del impreso, con el **código numérico** que el evaluador anota en la casilla y el **tipo de respuesta**.

Leyendas de escala que se reutilizan:

| Código | Grado de daño (ítems 4–10 y 13–16) |
| ---: | --- |
| 1 | Ninguno |
| 2 | Leve |
| 3 | Moderado |
| 4 | Fuerte |
| 5 | Severo |

## Inventario compacto (para el catálogo de campos)

Preguntas de **código único** (una casilla): 1–12, sistema estructural, tipo de entrepiso, año, usos, clasificación 1–5, clasificación previa, condiciones pre-existentes, efecto en ocupantes (sí/no/no se sabe), ocupación habitada.

Preguntas de **matriz**: 13–16 (cinco grados) y porcentaje global (seis rangos).

Preguntas de **marca múltiple**: visita especializada, intervención, medidas de seguridad, desconexión de servicios, instalaciones del ítem 9.

Preguntas de **texto / número libre**: identificación, dirección, dimensiones, pisos, lugares de medidas, contacto, comentarios, comisión, fecha.

Preguntas de **archivo**: esquema (croquis), foto de tarjeta profesional (fuera de este formato; es del registro del evaluador).
